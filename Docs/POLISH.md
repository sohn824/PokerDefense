# 포커 디펜스 — 퀄리티 업 백로그

> 게임의 **완성도·게임필·명료성** 개선 항목을 모은다. 새 시스템 설계는 [DESIGN.md](DESIGN.md)가, 수치 밸런싱은 ScriptableObject 데이터가 담당한다 — 이 문서는 둘 다 다루지 않는다.
> 방향은 "새 기능 추가"가 아니라 **이미 있는 것을 제대로 보이게·느끼게** 하는 것이다.
> 착수한 항목은 완료 시 [HISTORY.md](HISTORY.md)에 기록하고 여기서 지운다.
> 공수 표기: **S** 반나절 이하 / **M** 하루~이틀 / **L** 그 이상.

---

## 우선순위

"게임이 미완성으로 보임"의 대부분이 이 셋에서 나온다.

| # | 항목 | 공수 | 왜 먼저인가 |
|---|---|---|---|
| 1 | 오디오 패스 (현재 무음) | M | 코드 대비 체감 상승이 가장 크다. 게임필의 절반 |
| 2 | 화면 프레임 — 트랙 아레나화 (§7-4 Phase B) | M | HUD·카메라는 해결(Phase A, 2026-09-02). 남은 건 "링 안의 작은 섬"으로 보이는 트랙 아트 — 아트 필요 |
| 3 | 성공·실패 연출 | S~M | 지금은 "타이머 끝 → 잔여 적 세기"뿐이라 성공도 실패도 밋밋하다 |

그다음: **전투 전 위협 미리보기** + **라운드 전환 비트**가 루프 만족감을 올린다.

## 1. 오디오 — 공수 M

무음 상태로 추정된다. 개별 항목은 대부분 S, 합쳐서 M.

| 대상 | 내용 |
|---|---|
| UI | 카드 딜·플립, Chip 획득(동전), 유닛 배치(쿵), 버튼 |
| 머지 | **별이 오를수록 높아지는 차임** — ★1→2와 ★2→3을 소리로 구분 |
| 전투 | 유닛별 발사음(공격 패턴 5종 구분), 피격, 처치, 보스 등장, 관통·스플래시 착탄 |
| 족보 확정 | **티어별 스팅어** — 하이카드는 툭, 스트레이트+는 잭팟 |
| 상태 | 라이프 손실(경보), 웨이브 클리어(징글), 게임오버 |
| 음악 | Act별 트랙, 또는 강도 레이어 1개(계획 단계 ↔ 전투) |

## 2. 화면 프레임 (§7-4) — 공수 M

`TrackMargin 0.9`는 밸런스 락이다 — 중앙 칸이 트랙에서 정확히 2.4, 최단 사거리 2.5의 근거([HISTORY.md] 반복 함정 "사거리는 자유롭게 못 내린다"). 이 값은 건드리지 않고 프레임만 손본다.

| 항목 | 내용 | 공수 | 상태 |
|---|---|---|---|
| 카메라 리프레임 | 보드를 화면 중앙~하단으로 내리고, 상단에 HUD 전용 공간 확보 | M | **완료 (2026-09-02)** — 카메라 Y 0→1.0 |
| HUD 위젯화 | 라이프·Chip·조커·라운드를 트랙 위 떠 있는 라벨 → 상단 바 안 위젯으로 | S | **완료 (2026-09-02)** |
| **트랙 여백 연출** | 여백을 줄이는 대신 아레나로 — `TrackLoop`이 "구멍 뚫린 액자"라 15칸이 그 구멍에 뜬 섬처럼 보임. 바깥 전투 레인 + 중앙 단상 구조로 아트 교체 | M | **남음 — 아트 필요.** 프롬프트는 이전 대화(2026-09-02) 참고, 재요청 시 여기 채움 |
| 라벨 아웃라인 | 어두운 배경 위 HUD 가독성 | S | HUD 바로 해결돼 불필요 |

> 2026-08-30 라벨 이동 1차 → 2026-09-02 Phase A(카메라·HUD 바) 완료. 상세는 [HISTORY.md] 2026-09-02. 남은 건 트랙 아트뿐(Phase B).

## 3. 성공·실패 연출 — 공수 S~M

| 항목 | 내용 | 공수 |
|---|---|---|
| **웨이브 실패 연출** | 시간초과 시 남은 적이 트랙을 "돌파"하며 붉은 섬광 + 라이프 카운터가 펀치와 함께 깎임. `LifeDamageFor`(§5.4)가 계산만 하고 화면엔 안 보이는 상태 | S~M |
| **상위 족보 축포** | 스트레이트+ 확정 시 전체 화면 플래시 + 해당 유닛 등장 연출 + 사운드 스팅. §13(카드 상점)의 목표 "번 것처럼 느껴지는가"를 여기서 해결 | S~M |
| 피격 피드백 | 적 흰색 플래시 + 스케일 펀치 | S |
| 화면 흔들림 | 보스 피격·처치, 라이프 손실 | S |
| 보스 등장 | "WAVE 20 — BEHEMOTH" 배너 + 체력 바 + 트랙 글로우 변화 | S~M |

|---|---|---|
| **전투 전 위협 미리보기** | 다음 웨이브 구성을 아이콘으로("Swarm ×37, Runner ×24, Brute ×7"). "어떤 족보를 원하는가" 결정에 근거가 생김 | S |
| 배치 시 사거리·기여 표시 | 사거리 원 + 예상 DPS 기여 | S |
| 머지 슬롯 하이라이트 | 이미 일부 존재. 시인성 강화 | S |
| 유닛 툴팁 | 이름·패턴·사거리·DPS | S |
