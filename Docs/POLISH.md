## 1. 오디오 — 공수 M

2026-09-11 현재 채택 상태: SFX 33큐/55 WAV와 BGM 1곡. **Arena Breaks(124 BPM / 77.419초, 기타 펑크·베이스·브레이크비트)**를 채택했고, 씬의 준비·전투·보스·결과 음악 슬롯은 모두 `bgm_combat.wav`를 참조한다. 이전 준비/보스/결과 후보 파일은 Git 제외 대상이며 현재 4곡을 번갈아 재생하는 상태가 아니다.

카드 딜은 손패당 1회. 로열 라이플은 CC0 G36 표기 압축 소스의 3편집 변형(실사격 여부 미확인), 하이카드·원페어 권총은 실제 1911 녹음 가공본을 사용한다. 남은 일은 폰 스피커에서 전투 밀도에 따른 총성·BGM 균형과 반복 청취 피로 확인이다. 채택 후보를 다시 고르는 작업으로 되돌리지 않는다.

> 에셋별 상태와 과거 피드백은 [AUDIO_REQUEST.md](AUDIO_REQUEST.md), 생성·검증 방법은 Tools/Audio/README.md. 기존 WAV는 Artifacts/Audio/BeforePolish/에 보관. 아래 표는 이번 패스에서 연결한 범위다.

| 대상 | 내용 |

| UI | 카드 딜·플립, Chip 획득(동전), 유닛 배치(쿵), 버튼 |
| 머지 | **별이 오를수록 높아지는 차임** — ★1→2와 ★2→3을 소리로 구분 |
| 전투 | 유닛별 발사음(공격 패턴 5종 구분), 피격, 처치, 보스 등장, 관통·스플래시 착탄 |
