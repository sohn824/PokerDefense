**검증:** 단순 화면 캡처에 더해 실제 휴대폰에서 카드 교체, 잠긴 카드, 트레이 취소, 이동/머지/교환, 보드 만석, Chip 부족, 상점 가득 참, 빠른 연타를 확인한다. UI 변경 후 게임 규칙 테스트와 별개로 모달 입력 차단·단일 소비·단일 전이 회귀를 확인한다. 사람 관찰은 DESIGN §15.7을 따른다.

## 1. 오디오 — 공수 M

청취 수정 반영: 종이 질감 카드 3변형, 딜 1회 재생, 공용 클릭 중복 제거, 짧은 보상음, 어두운 150 BPM 비트 중심 BGM 4곡. Artifacts/Audio/PolishV2에서 청취 확인.

2026-09-06 최신: 32개 SFX 큐(52개 파일) + BGM 4곡. 전투곡은 새 C단조 반복음 주제·상행 응답·연속 타악으로 재작곡했으며 현악·호른·하프·큰북·팀파니를 CC0 실제 악기 샘플로 교체했다. 로열 라이플은 CC0 G36-E Fire 공개 압축 소스의 3편집 변형(실사격 여부 미확인)으로 교체했다. 새 BGM 청취본은 Artifacts/Audio/ArenaSmooth, 총성은 FantasyMelodyRework. 남은 일은 폰 스피커 청취, 음색·선율 채택 판단, 새 전투곡과 기존 준비/보스곡 사이 전환 청감 확인이다.
