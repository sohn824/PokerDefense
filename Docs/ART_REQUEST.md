## 1. 확정 스펙 (배경·트랙에도 적용)

| 항목 | 값 | 근거 |
|---|---|---|
| 스타일 | 일본 아니메 / JRPG·가챠 카드 아트 / 소프트 셀 셰이딩 | 유닛·적과 톤 통일 |
| 해상도 기준 | 1080×1920 (9:16) 모바일 세로 | |
| 배경 | 투명 PNG (배경 이미지 자체는 예외). 그림자·바닥선·프레임 없음 | |
| PPU | 스프라이트의 픽셀 높이 (높이 = 1 월드유닛) | |

### 판별 크기 — 캔버스보다 이쪽이 진짜 조건이다

1 월드유닛 = 145.5px.

| 요소 | 월드 크기 | 화면 px |
|---|---|---|
| 보드 슬롯 | 0.92 | 134 |
| 유닛 아트 | 0.85 | 124 |
| 적 | 0.50 (× `visualScale`) | 73 |
| 트랙 전체 | 6.8 × 4.8 | 989 × 698 |
| 배경 | 화면 전체 | 1080 × 1920 |

**캔버스를 크게 잡는 것은 축소 여유일 뿐 디테일을 넣으라는 뜻이 아니다.**

### 모션

프레임 애니메이션을 만들지 않는다. 유닛 아트는 방향당 1장이고 움직임은 `UnitSlotView`가 스케일로 낸다(발사 반동 +6% / 대기 호흡 ±1.5%). 적·카드·배경은 정적 1장.

## 2. 5단계 — 배경·트랙 4장 (신규)

교체가 아니라 신규다. 지금은 트랙이 아예 안 그려지고 카메라가 단색 `(0.1, 0.1, 0.12)`으로만 지운다.

| 파일 | 캔버스 | 내용 |
|---|---|---|
| 전체 배경 | 1080×1920 | 화면 전체. 트랙·보드·HUD가 그 위에 얹힌다 |
| 트랙 텍스처 | 989×698 영역 | 그리드를 감싸는 닫힌 사각 루프. 적이 이 위를 순회한다 |
| 빈 슬롯 타일 | 134px | 15칸 그리드의 빈 칸 배경 |
| 슬롯 하이라이트 프레임 | 134px | 유닛을 고르면 이동·머지 가능 칸에 뜬다 |

**여기서 함께 정리할 것:**
- 슬롯 하이라이트가 그 칸의 아트를 밝게 뜨게 하는 방식(현재 `Color.Lerp`) 재검토.
- 트랙 텍스처가 화면 하단 안내 문구 자리(DESIGN §7-4)를 침범하지 않게.

**받으면 잴 것:**
- 배경 위에서 유닛(124px)·적(73px) 실루엣이 여전히 읽히는가 (배경이 너무 밝거나 복잡하면 안 됨).
- 트랙 루프가 4구간(상단·우측·하단·좌측)에서 폭이 균일한가 — 적이 구간을 돌 때 튀지 않게.
- 트랙 텍스처 알파: 루프 밖은 투명, 배경이 비쳐야 한다.

## 4. 완료된 아트 — 임포트 설정 (재작업 시 참조)

- **유닛/적 시트:** `Sprite/Single`, `npotScale = None`, `PPU = 스프라이트 높이`, `Bilinear`, 밉맵 켬, 피벗 `BottomCenter`(`alignment: 7` — 메타 되읽어 확인), `Alpha Is Transparency` 켬.
- **이펙트:** PPU = 캔버스 폭(`bounds.size`가 `(1,1)`이 되어 스케일 공식이 그대로 성립), alignment Center, `npotScale None`.
- **카드:** `CardFront` 9-slice `spriteBorder 240`·FullRect·maxTextureSize 1024, 무늬 4장 Center pivot·maxTextureSize 256.
- **후처리 스크립트:** `Docs/tools/cardfront_composite.py`(테두리만 남기고 안쪽 평탄 크림), `Docs/tools/suit_sheet_crop.py`(2×2 무늬 시트 4등분·높이 통일).

### 2×2 시트를 자르는 절차 (유닛·적 공통, 배경엔 불필요)

1. 시트를 `Art/<Units|Enemies>/<이름>/`에 넣는다.
2. **자르기 전에 실제 분리 행·열을 찾는다** — 세로·가로 중앙선 통과 픽셀을 세고, 걸리면 위 칸이 끝나는 행과 아래 칸이 시작하는 행 사이에서 자른다(균등 분할이면 얼룩이 섞여 바닥 정렬이 깨진다).
3. 알파 트림 → 네 장 높이 편차 확인(크면 부츠 비율로 "몸이 진짜 작은지 vs 포즈 차이인지" 가른다).
4. **아래 두 칸이 실제로 어느 쪽을 보는지 확인** — 프롬프트에 박아도 뒤바뀐다. 무기 띠 x중심 vs 다리 x중심으로 판정, 뒤바뀌었으면 엇갈려 배정.
5. 공통 캔버스에 가로 중앙·아래 정렬로 다시 채운다.
6. 유기적 형태(촉수·머리카락·날개)는 **연결 성분 검사**로 고립 조각이 없는지 확인.

## 5. M11 범위 밖

- 투사체 3종 — §5.5가 즉시 히트로 못 박았다.
- 버튼 프레임 / HUD 아이콘 / 결과 팝업 — 검증 조건에 안 걸린다.
- 피격·소환·머지 이펙트, 희귀 족보 등장 연출 — 연출 단계에서 §10.4의 3단계 스케일 규칙과 함께.
- 카드 뒷면 — 덱 더미·페이스다운·플립 연출이 없어 어떤 코드도 뒤집힌 카드를 안 그린다.
