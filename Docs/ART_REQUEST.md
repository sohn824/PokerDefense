# 아트 리소스 요청 목록

생성형 AI로 제작할 이미지 목록이다. **구현은 플레이스홀더(단색 도형)로 진행하고 이 목록은 M11에서 한꺼번에 교체한다.**
지금 당장 만들 필요는 없고, 스타일만 먼저 확정해 두면 좋다.

> **유닛 13종의 컨셉·이름·실루엣 규칙은 [DESIGN.md](DESIGN.md) §10.2~10.4가 유일한 출처다.** 여기에 중복해 적지 않는다.
> 적 5종도 §10.5를 따른다.

## 공통 스펙 (먼저 확정할 것)

| 항목 | 제안값 | 비고 |
|---|---|---|
| 스타일 | 2D 카툰 / 두꺼운 아웃라인 / 채도 높은 색 | 생성 프롬프트에 고정 문구로 재사용 |
| 시점 | 쿼터뷰 느낌의 정면 스프라이트 | 유닛·적 전부 동일 |
| 배경 | **투명 PNG** | 전부 |
| 캔버스 | 유닛·적 256×256, 아이콘 128×128, 카드 256×358 (7:10) | Unity에서 PPU로 축소 |
| 해상도 기준 | 1080×1920 (9:16) | 모바일 세로 |

**먼저 유닛 1종을 확정한 뒤 그 이미지를 스타일 레퍼런스로 물려 나머지를 생성**하는 순서를 권장한다.

## 1. 유닛 (13종) — 우선순위 최상

컨셉은 DESIGN §10.2 표를 그대로 따른다. 아트 작업에서 추가로 지켜야 할 것:

- **족보 구조를 실루엣으로 표현한다.** 2 / 2+2 / 3 / 3+2 / 4가 읽혀야 한다 (§10.2).
- **성급이 올라도 구조 숫자를 바꾸지 않는다** (§10.4). ★2/★3은 별도 스프라이트 대신 **오라 오버레이 1장 + 색조 변경**으로 대체한다. 13종 × 3 = 39장을 만들지 않아도 된다.
- 카드 문양은 유닛마다 **고정 심볼 하나**만 쓴다. 실제 손패 무늬에 따라 바뀌지 않는다.
- 소버린만 실루엣을 약간 크게 잡는다.

## 2. 적 (5종)

Normal / Runner / Tank / Swarm / Boss. 특성은 §10.5 참조 — HP·속도·수량만 다르고 특수 능력은 없으므로 **실루엣 크기와 색으로 구분**되면 충분하다.

## 3. 카드

- 카드 뒷면 1장
- 카드 앞면: **프레임 1장 + 무늬 4종 + 숫자 폰트** 조합으로 런타임 합성 → 52장을 개별 생성하지 않는다
- 무늬 아이콘 4종 (♠♥♦♣)
- 카드 선택/교체 하이라이트 프레임 1장

## 4. 맵 / 배경

- 그리드 타일 (배치 가능 / 점유됨 / 하이라이트 = 3상태)
- 그리드 바깥 트랙(적 이동 경로) 텍스처
- 전체 배경 1장

## 5. UI

- 버튼 프레임 (기본 / 눌림 / 비활성)
- HUD 아이콘: **Chip**, 라이프, 라운드, 타이머, Joker
- 족보 결과 배너 프레임
- 결과 팝업 (클리어 / 실패)

## 6. VFX (이미지 기반)

- 투사체 3종 (화살 / 마법탄 / 포탄)
- 피격 / 소환 / 머지 이펙트 각 1종
- 희귀 족보 등장 연출 오버레이 — **스트레이트 플러시 이상 3단계로 스케일**한다 (§10.4)

## 생성 시 주의

- **투명 배경 PNG로 뽑을 것.** 배경이 들어가면 제거 공정이 추가된다.
- **좌우 방향 통일.** 유닛은 오른쪽을 보게 하고 반대는 스프라이트 플립으로 처리한다.
- **동일 프롬프트 접두어를 고정**해서 13종 간 톤이 튀지 않게 한다.
