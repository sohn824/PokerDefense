# 아트 리소스 요청 목록

생성형 AI로 제작할 이미지 목록이다. **구현은 플레이스홀더(단색 도형)로 먼저 진행하고, 이 목록은 M6에서 한꺼번에 교체한다.**
따라서 지금 당장 만들 필요는 없고, 스타일만 먼저 확정해 두면 좋다.

## 공통 스펙 (먼저 확정할 것)

| 항목 | 제안값 | 비고 |
|---|---|---|
| 스타일 | 레퍼런스와 동일한 **2D 카툰 / 두꺼운 아웃라인 / 채도 높은 색** | 생성 프롬프트에 고정 문구로 재사용 |
| 시점 | 쿼터뷰 느낌의 정면 스프라이트 | 유닛·적 전부 동일 |
| 배경 | **투명 PNG** | 유닛/적/UI 아이콘 전부 |
| 캔버스 | 유닛·적 256×256, 아이콘 128×128, 카드 256×358 (7:10) | Unity에서 PPU로 축소 |
| 해상도 기준 | 1080×1920 (9:16) | 모바일 세로 |

> 스타일 일관성을 위해 **먼저 유닛 1종을 확정한 뒤, 그 이미지를 스타일 레퍼런스로 물려 나머지를 생성**하는 순서를 권장한다.

---

## 1. 유닛 (13종) — 우선순위 최상

`HandCategory` 하나당 유닛 1종. 족보가 강할수록 시각적으로 강해 보여야 한다.

| # | 족보 | 유닛 컨셉 방향 (수정 자유) |
|---|---|---|
| 1 | 하이카드 | 최하급 잡병 — 몽둥이 든 고블린급 |
| 2 | 원페어 | 기본 병사 2인 1조 느낌 |
| 3 | 투페어 | 쌍검 / 이도류 |
| 4 | 트리플 | 삼지창 병사 |
| 5 | 스트레이트 | 궁수 (일렬 관통 이미지) |
| 6 | 플러시 | 마법사 (단일 속성 = 단일 무늬) |
| 7 | 풀하우스 | 중장갑 기사 |
| 8 | 포카드 | 4연장 포탑 / 중화기 |
| 9 | 스트레이트 플러시 | 상급 마법 궁수 |
| 10 | **백스트레이트** (특수) | 역방향 컨셉 — 어둠/역재생 느낌 |
| 11 | **마운틴** (특수) | 산·거인 컨셉 |
| 12 | **백스트레이트 플러시** (특수) | 10번의 각성 형태 |
| 13 | **로열 스트레이트 플러시** (특수) | 최종 유닛 — 왕관/황금/광휘 |

각 유닛당 필요한 것:
- 기본 스프라이트 1장
- (선택) ★2 / ★3 이펙트 — 별도 이미지 대신 **오라 이펙트 오버레이 1장 + 색조 변경**으로 대체 가능. 13종 × 3 = 39장을 만들지 않아도 됨

## 2. 적 (초기 4종)

| 종류 | 컨셉 |
|---|---|
| 일반 | 기본 잡몹 |
| 고속 | 작고 빠른 몹 |
| 탱커 | 크고 느린 몹 |
| 보스 | 5웨이브마다 등장 |

## 3. 카드

- 카드 뒷면 1장
- 카드 앞면: **프레임 1장 + 무늬 4종 + 숫자 폰트** 조합으로 런타임 합성 → 52장을 개별 생성하지 않는다
- 무늬 아이콘 4종 (♠♥♦♣)
- 카드 선택/교체 하이라이트 프레임 1장

## 4. 맵 / 배경

- 그리드 타일 (배치 가능 / 점유됨 / 하이라이트 = 3상태)
- 그리드 바깥 트랙(적 이동 경로) 텍스처
- 전체 배경 1장 (레퍼런스처럼 숲/들판)

## 5. UI

- 버튼 프레임 (기본 / 눌림 / 비활성)
- HUD 아이콘: 골드, 라이프, 웨이브, 타이머
- 족보 결과 배너 프레임
- 결과 팝업 (클리어 / 실패)

## 6. VFX (이미지 기반)

- 투사체 3종 (화살 / 마법탄 / 포탄)
- 피격 이펙트 1종
- 소환 이펙트 1종
- 머지 이펙트 1종
- 특수 족보 연출용 광휘 오버레이 1종

---

## 생성 시 주의

- **투명 배경 PNG로 뽑을 것.** 배경이 들어간 이미지는 배경 제거 공정이 추가로 필요하다.
- **좌우 방향 통일.** 유닛은 오른쪽을 보게 통일하고, 반대 방향은 스프라이트 플립으로 처리한다.
- **동일 프롬프트 접두어를 고정**해서 13종 간 톤이 튀지 않게 한다.
